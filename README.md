# davi-privacy

다비(davi) 개인정보처리방침의 **게시용 저장소**다. GitHub Pages로 서는 페이지가 Play Console과
앱의 `consent_policy_url`이 가리키는 주소다.

- 게시 주소: https://flyai-kfc.github.io/davi-privacy/
- 내용: [`index.md`](index.md)

## 원본은 여기가 아니다

**원본은 `flyai-kfc/davi` 저장소의 `docs/PRIVACY-POLICY.md`다.** 이 저장소의 `index.md`는
그 파일의 사본이며, **고칠 때는 원본을 먼저 고치고 그 결과를 여기로 복사한다.** 반대 방향으로
고치면 원본이 사본을 따라가게 되어 「코드가 근거」라는 규칙이 끊긴다.

원본에는 줄마다 근거가 되는 코드 위치가 적혀 있다. 그 표기를 게시본에서 지우지 않는다 —
무엇을 근거로 한 약속인지가 읽는 사람에게도 유효한 정보다.

## 문서 버전

문서 머리의 **문서 버전은 앱의 `consent_version`과 같은 값을 센다.** 한쪽만 올리지 않는다 —
어느 문안에 동의했는지 판정할 수 없게 되고, 그 판정이 재동의의 근거다.

## 이 저장소가 공개인 이유

Play는 공개적으로 접근 가능한 처리방침 URL을 요구한다. 개발 저장소(`flyai-kfc/davi`)는
private이라 그 주소를 낼 수 없어, **게시에 필요한 것만** 이 저장소에 둔다. 코드는 넣지 않는다.
